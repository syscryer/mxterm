# 实现复制连接

## Goal

允许用户基于已有连接创建一个可编辑的新连接副本，减少重复录入相似主机配置的成本。

## Confirmed Facts

- 用户所说的“复制连接”是复制已有连接配置并生成副本。
- 不包含复制地址、复制 SSH 命令或其他剪贴板功能。
- 当前左侧连接树已有“打开、编辑、收藏、删除”右键菜单。
- 当前新建与编辑共用连接弹窗；编辑态会从已有连接预填非敏感配置。
- 内联密码和私钥口令保存在后端安全存储中，连接列表和编辑表单不会把秘密明文回传前端。

## Requirements

- 左侧连接树右键菜单增加“复制连接”，位置在“编辑连接”之后、“收藏”之前。
- 复制入口仅出现在左侧连接树右键菜单；首页连接表格不增加右键入口。
- 复制流程使用现有连接弹窗预填配置，并明确显示复制语义及创建副本动作。
- 仅在用户确认创建后持久化副本；关闭弹窗不得留下多余连接。
- 副本使用新的连接 ID，并生成不冲突的名称。
- 复制连接时保留协议及用户配置，包括分组、代理、跳板机、终端和协议专属配置。
- 不复制收藏、最近连接时间、远端系统探测结果等运行状态。
- 首页连接表格不新增第四个常驻操作图标。
- 复制过程不得把密码或私钥口令明文暴露给前端。
- 副本完整继承原连接的认证信息；内联密码和私钥口令由后端安全复制。
- 副本创建后的编辑与密码查看能力应和原连接一致，继续遵循现有密码显示权限与交互。
- 不新增第三方依赖，不引入未被当前需求使用的通用复制框架。

## Acceptance Criteria

- [x] 用户可从左侧连接树的右键菜单进入复制流程。
- [x] 复制弹窗正确预填原连接的非运行态配置，并允许用户修改。
- [x] 关闭复制弹窗不创建任何副本。
- [x] 确认创建后新增一条独立连接，修改或删除副本不影响原连接。
- [x] 弹窗为副本生成不冲突且可理解的默认名称；用户仍可在创建前修改名称。
- [x] 保存账号引用、每次询问和内联凭据三种认证模式均完整复制，副本可独立正常连接。
- [x] 副本中的密码查看行为与原连接一致，并继续受现有密码显示设置约束。
- [x] 收藏、最近连接时间和远端系统探测结果不会被继承。
- [x] SSH、RDP、VNC、Telnet、串口连接的配置复制行为均有验证覆盖。
- [x] 原有新建、编辑、删除、收藏和连接行为不回归。
- [x] 亮色、显式暗色及 system-dark 下沿用现有共享右键菜单和连接弹窗样式。

## Out of Scope

- 复制连接地址到剪贴板。
- 复制 SSH 命令到剪贴板。
- 首页操作列新增复制图标。
- 首页连接表格行增加复制右键入口。
- 批量复制多个连接。
