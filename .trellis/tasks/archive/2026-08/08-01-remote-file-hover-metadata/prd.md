# 增强远程文件悬浮信息

## Goal

让用户在远程文件树中悬停或键盘聚焦条目时，无需打开“属性”对话框即可快速辨认文件并查看常用元数据，同时保持现有紧凑的桌面工具界面和目录浏览性能。

## Confirmed Facts

- 当前远程文件树仅通过浏览器原生 `title` 展示条目的完整路径。
- 当前目录列表条目只包含名称、路径和类型；大小、权限和修改时间由现有远程属性查询单独获取。
- 项目已经使用 Radix Tooltip 和全局浮层样式，浮层需要兼容亮色、显式暗色和 system-dark。
- 远端文件系统不一定提供创建时间；远端系统也可能无法把 UID/GID 解析为用户名和组名。

## Requirements

- 使用项目共享的 Radix 浮层体系展示自定义远程文件信息卡，不使用浏览器原生 `title` tooltip。
- 自定义信息浮层覆盖文件树中的所有条目，保持文件与文件夹交互一致。
- 浮层展示条目类型、大小、所有者、所属组、权限、修改时间、创建时间和完整路径。
- 文件夹不展示大小，避免把目录项自身大小误认为目录内容总量；其他适用字段正常展示。
- 创建时间不可用时明确显示“系统不支持”，不得伪造或用修改时间代替。
- 所有者或所属组无法解析为名称时，回退显示 UID/GID；不可用时显示明确的未知状态。
- 元数据按需加载并缓存，不能因为鼠标经过大量条目而无延迟地触发大量远端请求。
- 浮层应支持鼠标悬停和键盘聚焦，不能成为访问“属性”功能的唯一入口。
- 保留现有右键“属性”入口，继续用于完整属性查看及相关操作。
- 视觉样式复用全局 `--mx-*` token、浮层材质和紧凑面板规范，不新增独立配色、阴影或玻璃体系。

## Acceptance Criteria

- [ ] 文件树条目不再触发浏览器原生路径 tooltip，且不会与自定义浮层重复显示。
- [ ] 悬停达到设定延迟或键盘聚焦条目后，显示紧凑的自定义信息浮层。
- [ ] 浮层覆盖文件树中的普通文件、文件夹、符号链接和其他条目。
- [ ] 普通文件正确显示类型、大小、所有者、所属组、权限、修改时间、创建时间和完整路径；文件夹不显示大小。
- [ ] 创建时间不受远端系统或文件系统支持时显示“系统不支持”。
- [ ] 所有者/所属组名称不可解析时回退到 UID/GID，并正确处理完全不可用的情况。
- [ ] 同一连接和路径的重复悬停复用缓存；目录刷新或连接切换后不会展示明显过期或串线的元数据。
- [ ] 元数据读取中、读取失败和条目已消失时均有稳定状态，不阻塞文件树点击、双击、拖拽、右键菜单和多选交互。
- [ ] 浮层可通过键盘聚焦触发，并在亮色、显式暗色、system-dark 下保持可读。
- [ ] 现有右键“属性”功能保持可用。

## Out of Scope

- 在文件树行内常驻展示第二行元数据。
- 用 hover 浮层替代右键“属性”对话框。
- 为不支持 birth time 的远端文件系统推算或生成创建时间。

## Notes

- 本任务涉及 React UI、TypeScript 命令契约、Rust 远端元数据解析和跨平台命令兼容，按复杂任务规划。
