# 活动标签支持中键关闭

## Goal

让桌面端所有可关闭的活动标签支持鼠标中键关闭，行为与标签现有关闭按钮一致，减少频繁切换和关闭会话时的操作成本。

## Confirmed Facts

- 顶栏连接会话、SSH 终端、本地终端、终端分屏组、远程文件和独立 VNC 会话均已有显式关闭按钮或关闭动作。
- 远程文件关闭可能触发未保存确认，中键不得绕过该流程。
- 首页、终端入口和右侧工具分类属于固定导航，不是可关闭活动标签。

## Requirements

- 在所有已有关闭能力的活动标签主体上处理中键点击。
- 仅响应鼠标中键（`button === 1`），左键选择、右键菜单和拖拽行为保持不变。
- 中键关闭必须调用标签现有关闭函数，不复制或重写关闭状态逻辑。
- 远程文件中键关闭必须保留脏文件确认和保存状态处理。
- 固定导航标签、添加按钮、滚动按钮和其他非关闭型页签不增加中键关闭。
- 不新增依赖，不改变现有视觉样式和主题表现。

## Acceptance Criteria

- [x] 顶栏连接会话可用中键关闭。
- [x] SSH 与本地终端子标签可用中键关闭。
- [x] 终端分屏组标签可用中键触发原关闭流程。
- [x] 远程文件标签可用中键关闭，未保存文件仍出现原确认流程。
- [x] 独立 VNC 会话标签可用中键关闭。
- [x] 左键选择、右键菜单、标签拖拽、关闭按钮和固定导航行为无回归。
- [x] TypeScript 检查、生产构建和启动模块边界检查通过。

## Out of Scope

- 为固定导航页签增加关闭能力。
- 新增中键提示文案、设置开关或自定义鼠标按键映射。
- 改造标签视觉样式。
