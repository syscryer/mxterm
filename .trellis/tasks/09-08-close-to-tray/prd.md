# 关闭窗口时最小化到系统托盘

## 目标与用户价值

用户误点主窗口右上角关闭按钮或使用 Alt+F4 时，MXterm 不应立即结束进程并断开现有会话。开启该选项后，主窗口隐藏到系统托盘，终端、SSH 连接和后台任务继续运行，用户可从托盘恢复窗口或明确退出程序。

## 已确认事实

- 主窗口的自定义关闭按钮目前调用 getCurrentWindow().close()；当前主窗口没有关闭请求拦截。
- 基础设置已通过 MxtermSettings.basic 存储在浏览器 localStorage，并由 normalizeSettings 处理旧数据；设置页已有复用的 SettingsRow 和 SettingsToggle。
- Tauri 后端当前为 2.11.2，尚未创建托盘图标；已有主窗口句柄访问和显式 app.exit 可用的后端入口模式。
- VNC/RDP 运行窗口拥有独立的关闭生命周期，不能把主窗口的关闭到托盘逻辑套用到这些窗口。

## 需求

1. 在“设置 > 基础设置”增加“关闭窗口时最小化到系统托盘”开关，默认开启。
2. 开关开启时，主窗口的标题栏关闭按钮、系统关闭按钮和 Alt+F4 都应拦截关闭请求，确保托盘已可用后隐藏主窗口；不得结束进程或断开现有连接。
3. 开关关闭时，保持现有关闭即退出行为。
4. 托盘提供“显示 MXterm”和“退出 MXterm”两个明确操作；退出必须真实结束应用，而不是再次隐藏窗口。
5. 恢复主窗口时，应显示、取消最小化并聚焦窗口。
6. 托盘初始化或隐藏窗口失败时，主窗口必须保持可见，并让用户能够感知失败；不得假装已成功最小化。
7. 设置缺失的历史本地配置按新默认值开启，并在下次写入时完成兼容归一化。
8. 不改变 VNC/RDP 独立运行窗口、更新重启流程和现有最小化按钮的语义。

## 验收标准

- [ ] 新安装及缺少该字段的历史设置默认开启“关闭窗口时最小化到系统托盘”。
- [ ] 开启后，点击主窗口关闭按钮或按 Alt+F4，MXterm 进程和已连接终端继续存在，主窗口从任务栏消失并可由托盘恢复。
- [ ] 托盘“显示 MXterm”可恢复、取消最小化并聚焦主窗口；“退出 MXterm”真实结束进程。
- [ ] 关闭开关后，关闭主窗口仍走现有退出路径。
- [ ] 多次连续关闭请求不会重复创建托盘或触发竞态错误。
- [ ] VNC/RDP 运行窗口关闭后仍只处理自身会话，不会隐藏主窗口。
- [ ] 设置 UI 复用项目共享控件，亮色、深色和 system-dark 下均可用。
- [ ] TypeScript 检查、前端构建、Rust 检查及桌面开发版人工路径均通过。

## 非目标

- 本次不新增开机自启、后台启动、托盘消息通知或跨设备同步设置。
- 本次不改变“最小化”按钮的行为，也不为每个子窗口引入托盘。

## 已确认交互决策

- 托盘图标左键单击：显示、取消最小化并聚焦主窗口。
- 托盘图标右键：显示系统菜单，提供“显示 MXterm”和“退出 MXterm”。
