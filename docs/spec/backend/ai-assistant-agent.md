# AI 助手 Agent 契约

## 工作区

Agent 每次运行必须明确当前终端主机，并可选绑定独立的本地文件工作区：

- 当前主机：保存的 SSH 连接，或当前本机终端。
- 本地文件工作区：用户明确选择的本地目录，可在 SSH 主机运行时单独启用。

命令、监控、后台任务和终端上下文必须跟随当前终端主机；文件工具使用明确授权的本地文件工作区，未选择时才使用当前 SSH 工作目录。后端不得根据模型输入猜测或切换作用域。

## 工具与权限

Agent 工具分为只读、需确认和用户输入三类。`execute` 模式下危险命令进入 `pending_approval`；`full` 模式跳过普通危险命令确认，灾难性根目录删除或磁盘破坏仍在执行前拒绝。审批结果由用户界面写入，模型不能自我批准。`ask_user` 使用独立的 `pending_user_input` 状态，可携带结构化 `options`、`allow_free_text`，用户回答通过独立的答案命令回传，不复用命令审批。

SSH 文件搜索优先调用 `rg`，不可用时回退到 `find` / `grep`。搜索命令不额外截断结果，不隐藏搜索错误；模型上下文和审计预览沿用统一的输出大小规则。

文件修改必须先生成 diff。应用修改前重新读取文件并校验旧内容；文件发生变化时拒绝写入。写入使用备份和原子替换，远程文件复用现有 SFTP 编辑限制。

后台任务返回稳定的任务 ID，支持查询状态、读取有界输出和取消。任务取消必须终止本地子进程或关闭远程执行通道。

## 执行生命周期

Agent 不设置固定工具调用轮次上限。模型继续返回工具调用时，执行工具并将真实结果交回模型；模型不再请求工具时结束本次回复。每轮模型请求前及每个工具执行前检查用户停止状态，接口或审计错误按原错误流程结束。

## 审计

每次工具调用至少记录工具 ID、名称、工作区、连接、命令或文件路径、风险、审批结果、状态、开始/结束时间、退出码、输出截断标记和错误。日志内容需要限制大小并避免保存凭据。

## 验收

1. 本机和 SSH 远程终端都能执行验证命令；本地文件工作区可独立读取和搜索内容。
2. 工作区外路径被拒绝；文件被外部修改后旧 diff 不能覆盖。
3. `execute` 模式下危险命令必须二次确认；`full` 模式直接执行普通危险命令，灾难性操作仍被拒绝。
4. 长命令可后台运行、查询输出并取消。
5. 聊天历史能恢复工具调用和审批后的最终状态。

## 实施计划

按以下顺序逐项实现，每项完成后先验证再进入下一项：

- [x] **实时终端输出**：为终端会话增加有界 ring buffer、游标和截断信息，并绑定连接与会话。
- [x] **文件生命周期操作**：补齐 rollback、create、delete、rename，统一 diff、版本校验、备份和权限边界。
- [x] **后台任务管理**：持久化任务状态、输出和时间；应用重启后标记 interrupted；本地任务可真实终止，远程任务明确停止确认边界。
- [x] **审计日志界面**：增加查看、筛选和导出入口，确保 command、output、token、credential 脱敏。
- [x] **Agent 计划与提问 UI**：为 update_plan 和 ask_user 增加专用展示、确认和状态。
- [x] **安全回归**：完成路径边界、CAS 冲突、高危命令确认、审计失败即停、任务取消状态和前端/后端构建回归；Rust 单测执行受 Windows `0xc0000139` 测试清单问题阻断。

每一项都必须有可观察状态和验证结果，未完成的操作不能在界面显示为成功。
